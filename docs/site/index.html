Capabilities
Everything you need. Nothing you don't.

Service Pulse replaces heavyweight APM agents with direct SSH-based introspection — giving you full control without installing anything on your servers.

🔑
Keyless SSH CA Engine
Ephemeral Ed25519 keypairs signed by HashiCorp Vault SSH CA. Keys never touch disk — generated and zeroized in RAM. Proactive cert renewal at 75% TTL.
📡
Tiered Health Evaluation
Tier 1: Spring Actuator / HTTP health check. Tier 2: SSH process check via systemd or process scan. Per-server health check URL overrides supported.
📋
Live Log Streaming
SSE-based real-time log tailing direct from remote paths. Filter, pause/resume, auto-scroll, and clipboard copy — all without a WebSocket agent.
⚡
Remote Command Execution
Execute preconfigured or ad-hoc shell commands on any registered server. Output streams live to the terminal console panel. Exit codes tracked.
🔔
Alert Management
Configurable alert conditions with cron-based evaluation. Per-service lifecycle alerts with acknowledgement. UI badge indicators with pulse animations.
🗄️
Liquibase-Managed Schema
MySQL 8.0 schema versioned via Liquibase changelogs. Single consolidated V1__init.sql migration covers all tables and seeds. PostgreSQL migration roadmapped.
🐳
First-Class Docker Support
Single docker compose up spins app + MySQL + HashiCorp Vault + auto Vault SSH CA configuration. Swarm & K8s compatible with ShedLock for distributed scheduling.
🔭
Full Observability Stack
Spring Boot Actuator with all endpoints exposed. Micrometer metrics, audit logging for critical events (agent creation/deletion), and SSH command exit code telemetry.
🧪
E2E Playwright Test Suite
TypeScript Playwright automation for all UI pages. CI-ready with GitHub Actions. Covers server registration, service health checks, SSH command execution flows.
Architecture
Layered. Stateless. Secure.

Built for multi-replica Kubernetes and Docker Swarm environments. All SSH keys live in memory only — never serialized to container filesystems.

# docker-compose.yml — full stack
services:
  db:
    image: mysql:8.0
    healthcheck: mysqladmin ping

  vault:
    image: hashicorp/vault:latest
    environment:
      VAULT_DEV_ROOT_TOKEN_ID: root

  vault-init:
    # Auto-configures SSH CA role
    vault write ssh/roles/runner \
      key_type=ca ttl=1h

  service-pulse-app:
    environment:
      SSH_AUTH_MODE: CA_CERTIFICATE
      SSH_CA_ENDPOINT: http://vault:8200
      SSH_CA_KEY_ALGORITHM: ED25519
      SSH_CA_CERT_TTL_MINUTES: 60
      SSH_CA_RENEW_THRESHOLD_PERCENTAGE: 75

Quick Start
Up in 60 seconds.

Choose your deployment path. Docker Compose includes auto-configured Vault SSH CA.

Java 21+ Maven 3.9+ MySQL 8.0 Docker HashiCorp Vault
# Clone & launch (MySQL + Vault + app — all pre-configured)
git clone https://github.com/rsp777/service-pulse-app.git
cd service-pulse-app
docker compose up -d

# App available at:
open http://localhost:9092/service-pulse-app

# Actuator health check:
curl http://localhost:9092/service-pulse-app/actuator/health | jq
# Prerequisites: Java 21, Maven, MySQL running on mysql-server

# Run with local profile (uses mysql-server host)
mvn spring-boot:run "-Dspring-boot.run.profiles=local"

# Or set env vars manually:
$env:DB_URL = "jdbc:mysql://localhost:3306/service-pulse-app"
$env:SSH_AUTH_MODE = "STATIC"
$env:SSH_PRIVATE_KEY_PATH = "C:\secrets\id_ed25519"
$env:SSH_KNOWN_HOSTS_PATH = "C:\secrets\known_hosts"
mvn spring-boot:run
# Requires: GraalVM JDK 21 + Visual Studio Native Tools (Windows)
# Must run from: Native Tools Command Prompt

$env:JAVA_HOME = "C:\graalvm-jdk-21"
mvn clean -Pnative native:compile

# Run the native executable (~50ms startup):
.\target\service-pulse-app.exe

# Or on Linux:
./target/service-pulse-app
